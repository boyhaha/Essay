## **字典（dictionary）**
1. 字典的key可以是任意数据类型，但不能是可变数据类型，而且不可变的数据类型中某个元素也不能是可变的，
   * 例：（1,2，[1,2]）
2. 根据键访问值(key唯一)，若键不存在，会报错。
   * age = info.get('age', 18)
   * 若info中不存在'age'这个键，就返回默认值18，不会对字典做任何操作，若没有返回值，返回None
   * 若info中存在'age'这个键，就返回对应的值
3. age = info.setdefault('age', 18) 
   * 若info中不存在'age'这个键，就返回默认值18，并把该键值对插入字典中，若没有返回值，返回None
   * 若info中存在'age'这个键，就返回对应的值

4. 删除字典：
   1. del  info /  info.clear()               删除（清空字典）
   2. del info[key]                           删除指定键值对，key 不存在会报错，
   3. info.pop(key[,default])                 删除指定键值对，key 若不存在,返回default值，不设返回值会报错
   4. popiteam(）                             随机返回并删除字典中的一个键值对


5. 字典的其他内置函数

## **内置函数**
  * len(item),
  * max(item),
  * min(item),
  * del(item)
  * len操作字典时，返回的是键值对的个数
  * del有两种用法，一种是del加空格，另一种是del()
    * del a   /   del( a )
  * zip( )   将可迭代的对象作为参数，将对象中对应的元素打包成一个个元组，然后返回由这些元组组成的对象，这样做的好处是节约了不少的内存

```
>>>a = [1,2,3] 
>>> b = [4,5,6]
>>> c = [4,5,6,7,8] 
>>> zipped = zip(a,b) # 返回一个对象 
>>> zipped <zip object at 0x103abc288>
>>> list(zipped) # list() 转换为列表 [(1, 4), (2, 5), (3, 6)] 
>>> list(zip(a,c)) # 元素个数与最短的列表一致 [(1, 4), (2, 5), (3, 6)] 
>>> a1, a2 = zip(*zip(a,b)) # 与 zip 相反，*zip 可理解为解压，返回二维矩阵式 
>>> list(a1) [1, 2, 3] 
>>> list(a2) [4, 5, 6] 
```

### **2.字典和列表的不同以及使用字典的目的**

1. list是有序的，dict是无序的
2. list通过索引访问，dict使用key访问
3. list随着数量的正常增长要想查找元素的时间复杂度为O(n),dict不随数量而增长而变化，时间复杂度为O(1)
4. dict的占用内存稍比list大，会在1.5倍左右
5. dict的可读性更高
6. 特征决定用途：list一般可作为队列、堆栈使用，而dict一般作为聚合统计或者快速使用特征访问，可以存储一些有标识性的数据等


### **3.python set 的数据结构是怎样的**
在 Python 中，`set` 是一种 **无序、不重复** 的元素集合，基于 **哈希表（Hash Table）** 实现。它是一种类似数学中的集合的数据结构，主要用于存储和处理不重复的元素。

#### Python 中 `set` 的主要特征：

1. 无序性：
`set` 中的元素没有顺序，无法通过索引访问某个元素。元素的存储顺序不代表插入顺序。

2. 唯一性：
`set` 不允许出现重复元素。如果试图向 `set` 中添加已经存在的元素，集合会自动忽略重复的元素。

3. 可变性：
虽然 `set` 是可变的，即可以添加或移除元素，但 `set` 中的元素必须是 **不可变的**（如整数、字符串、元组等）。这要求 `set` 中的元素必须是可以被哈希的对象，例如：元组里面放list就不行。

#### `set` 的底层实现：

- **哈希表（Hash Table）**：Python 的 `set` 底层是通过哈希表来实现的。每个元素通过哈希函数计算一个哈希值，并将元素存储在哈希表中的对应位置。
- 哈希表使得 `set` 的 **查找**、**添加** 和 **删除** 操作在平均情况下具有 **O(1)** 的时间复杂度，即非常高效。
- 由于使用了哈希表，`set` 中的元素必须是可以计算哈希值的（不可变对象）。
- 默认初始化8个元素

#### 小结：
Python 的 `set` 基于哈希表，具有无序性和不重复性，支持高效的查找、插入、删除操作，并提供常见的集合运算。


### **4.python list 的数据结构是怎样的**
在 Python 中，`list` 是一种 **可变的、有序的** 数据结构，底层实现是 **动态数组（Dynamic Array）**。它可以存储不同类型的元素，并且元素可以重复。

#### Python 中 `list` 的主要特征：

1. 有序性：
`list` 保留元素的插入顺序，可以通过索引访问元素（从 0 开始）。由于其有序性，可以方便地进行元素的增删、修改以及查找。

2. 可变性：
`list` 是可变的，支持在现有列表中动态添加、删除或修改元素。

3. 动态性：
Python 的 `list` 底层是动态数组，意味着当列表需要增加容量时，它会自动扩展内部的存储空间。这种扩展通常伴随着 **内存重新分配** 和 **数据复制**，但对用户透明。

4. 元素类型：
`list` 中的元素可以是任何类型的对象（包括数字、字符串、对象、甚至是其他列表），且可以混合使用。

#### Python `list` 的底层实现：

- **动态数组**：Python 的 `list` 是基于 **C语言的动态数组** 实现的。最初分配一定的内存空间，当元素数量超过当前容量时，列表会自动扩展。通常会以 **几何增长** 的方式增加容量，避免频繁的内存重新分配。每次扩展时，列表会重新分配一块更大的连续内存空间，并将现有元素复制到新内存中。
  
- 动态数组提供了 **O(1)** 时间复杂度的 **索引访问** 和 **尾部添加** 操作，然而，插入和删除操作（特别是非尾部位置）可能涉及移动大量元素，时间复杂度为 **O(n)**。
- 为避免频繁申请内存空间，初始化时会检查缓冲池，PyListObject缓冲池默认大小为80。

#### `list` 扩容机制：
当 `list` 的容量不足时，Python 会按照一定的增长策略扩展内存（通常是按几何增长的方式，如每次增加 1.125 倍）。扩容时，系统会分配一块更大的连续内存并将原来的数据复制过去，这使得扩容本身具有 **O(n)** 的时间复杂度。不过，这种扩容操作是间歇性的，平常的 `append` 操作仍然是 **O(1)** 的。

#### 总结：
Python 的 `list` 底层是基于动态数组实现的，具有有序、可变的特点。它支持快速的索引访问和尾部添加，但在中间位置插入或删除时可能需要移动大量元素，因此效率较低。
